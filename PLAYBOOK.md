# MONEYWORKS PLAYBOOK — index

The playbook is split in two. Read the one for the format you are building and do not mix their rules.

**NEWEST (23 Oct 2026): long-form style = `STYLE_3D.md` (v6). It overrides `PLAYBOOK_LONG.md` and `UPGRADE.md` wherever they conflict.**

| You are building | Read | Format |
|---|---|---|
| A long-form episode (`epNN`) | **`PLAYBOOK_LONG.md`** | 1920×1080, 10–12 min, story spine, real photo every 10–15 s, trend meme every ~30 s |
| An upgrade of an existing long episode | **`UPGRADE.md`** | edit `pipeline/episodes/epNN.json` only, Dave hosts, photos/memes via beat fields |
| A vertical Short (`shortNN`) | **`PLAYBOOK_SHORTS.md`** | 1080×1920, 50–95 s, one loop, 10–14 photos, 2–4 memes |

Every "PLAYBOOK §x" reference in code, validator messages and briefs points to the same section number in `PLAYBOOK_LONG.md`. The Shorts rules that used to live in §0.9, §0.10 D and the "Episode 56 visual QA correction" are now in `PLAYBOOK_SHORTS.md`.

Rules for BOTH formats (owner, 11 Oct 2026): no commas in the spoken script (flowing sentences with connectors), real photos mixed with the drawings, trend meme formats recreated with our cast (never downloaded meme images).
